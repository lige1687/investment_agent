# 今日交易讨论室：影子模式说明

## 当前能力

“今日讨论室”用于中线题材和波段决策，回答：

1. 今天哪些持仓需要操作，以及建议区间是多少。
2. 通信、纳斯达克、全球基金等题材处于什么阶段。
3. 当前是否存在值得继续研究的题材或基金。

系统只生成讨论、条件和手动确认记录，不连接券商或基金销售平台下单。

## 冷启动

首次打开时自动导入“中线题材波段”模板。模板已包含：

- 明显机会门槛 80 分，65–79 分为条件操作。
- 账户回撤 5% 风险复核、7.5% 去风险候选、10% 保护参考。
- 止损优先级：逻辑失效、有效趋势破坏、用户明确启用的百分比止损。
- 百分比止损默认关闭。

用户只需先确认题材或基金的目标仓位。系统不强制“核心批、确认批”等批次，也没有隐藏的单次操作上限。

## 可信执行边界

- 行情、持仓、基金净值和公告都保存来源、时间和置信度。
- 模拟、过期、缺少关键时间或低置信度输入可以用于解释，但不能形成立即执行结论。
- 主动基金的公开持仓必须带报告期；主题暴露是推断，不表述为当天真实调仓。
- 基金管理人申购公告通过已安装的 `announcement-search` Skill 调用同花顺问财，并按生效日期还原当前状态。
- 基金公司公告不能证明支付宝、天天基金等销售渠道今天一定可下单。渠道未人工确认时，最多为条件操作。
- 公告状态为 `UNKNOWN` 时不生成“护栏后可执行金额”。
- 最终金额仅受基金管理人限额、目标仓位空间、实际可用现金和在途买单约束；金额仍由用户确认。
- 基金级目标仓位可以直接复算金额；题材级目标仓位必须先具备账户内全部基金的题材暴露汇总。汇总缺失时不借用单只基金仓位代替，而是停止生成可执行金额。

## 专业席位

- 组合风险：先检查账户回撤、集中度、现金和题材暴露。
- 市场环境：判断市场状态和买入许可。
- 主题与基金：判断题材阶段、公开持仓报告期和推断暴露。
- 买入评估：输出分数、触发条件、失效条件和建议区间。
- 卖出与保护：按逻辑失效、趋势破坏、止盈/止损优先级提出减仓意见。
- Skeptic：只查证据真实性和逻辑漏洞，不得改分、给金额或制造新的市场观点。
- Recorder / Chair：只整理已有结论，并且不能突破确定性护栏。

所有席位读取白名单 Skill 的完整内容和直接引用文件，并保存 SHA-256 版本。Skill 缺失或会话中变化时，该席位标为不可用。

## DeepSeek 配置

在 `backend/.env` 中配置：

```dotenv
LLM_PROVIDER=deepseek
LLM_MODEL=deepseek-v4-flash
LLM_API_KEY=你的_DeepSeek_API_Key
IWENCAI_API_KEY=你的_同花顺问财_API_Key
MARKET_DATA_MODE=live
```

密钥只在后端读取，不进入会话数据库、前端响应或错误信息。结构化输出失败只修复一次，第二次仍失败时该席位标为不可用。

## 本地运行

```bash
cd backend
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

```bash
cd frontend
npm run dev
```

访问 `http://localhost:5173/trading-room`。

## 影子模式检查清单

正式依赖它操作前，建议至少连续观察若干个交易日：

- 对照支付宝/天天基金验证申购状态与限额。
- 对照基金公司公告验证生效日期、客户类型和份额类别。
- 记录采纳、部分采纳、忽略或继续观察，以及实际金额。
- 检查“今天不操作”是否被正常保留，而不是为了给建议强行制造交易。
- 复盘 7 日和 30 日结果后再调整机会门槛和目标仓位。

当前仍需人工确认销售渠道状态、在途订单和可用现金；系统不会自动下单，也不承诺收益。
